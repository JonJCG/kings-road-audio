# The King's Road — KJV chapter audio

One MP3 per chapter of the King James Version (1,189 files), used by The King's
Road app. Files live in this repo's **releases**, not the git tree:

- `kjv-ot` — Old Testament, `GEN-001.mp3` … `MAL-004.mp3` (929 files)
- `kjv-nt` — New Testament, `MAT-001.mp3` … `REV-022.mp3` (260 files)

Book codes are USFM (GEN, EXO, … 1CO, … REV); chapters are zero-padded to three digits.

**Source and licence.** Synthesized narration from publicdomainaudiobibles.com,
"placed into the public domain in 2018. It can be used without restriction." The
King James Version text is in the public domain in the United States. These
copies are the originals remuxed with a Xing header (stream copy, no re-encode)
so players report the correct length and seek accurately.
